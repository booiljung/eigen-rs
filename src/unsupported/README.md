# Unsupported / Experimental Features

This module (`eigen_rs::unsupported`) contains features that are experimental or not yet fully supported by the core library guarantees.

## Stability
Features in this module are **not** subject to the same stability guarantees as the core library. APIs may change or be removed in minor versions.

## Contents
- **Matrix Functions**: Matrix Exponential (`MatrixExponential`) and Logarithm (`MatrixLogarithm`), ported from Eigen's unsupported module.
- **Polynomials**: (Planned) Polynomial solvers and utilities.
- **AutoDiff**: (Planned) Automatic differentiation support.

Use with caution in production environments.
